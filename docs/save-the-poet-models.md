# Save the Poet: 3D figures to make

Prompts for the figures in the Forum scene, to paste into a text-to-3D tool
(Meshy, Tripo or similar). Make each one separately and send me the files.

**For every figure:**

- Export as **GLB** (or FBX if GLB is not offered), with textures.
- Choose **A-pose** (arms slightly away from the body) if the tool offers a pose option. I add the animation myself.
- One person per file, standing, **no base or plinth**, nothing in the hands unless the prompt says so.
- If the tool has a style setting, choose **realistic**, not cartoon.
- Note which tool and which plan you used for each one. Free plans often restrict reuse, and the site needs to say what each model may be used for.

The setting is **Rome, 62 BC**. Romans wear the **toga** (a large draped
white wool garment) over a **tunic**; Greeks wear a **chiton** with a
**himation** (a cloak). No armour, no helmets, no capes, no gold jewellery,
no laurel wreaths.
